# Stories product vault

This folder is the tracked product specification and Obsidian vault for Stories.

Start at [[00 Product Home]]. The home page is the short orientation; the numbered folders hold the detailed strategy, requirements, quality bar, and delivery record.

The vault is documentation only. Runtime code lives in `src/`, `apps/mobile/`, and `packages/core/`. The separate `docs/product/` folder contains implementation and design references, not a second product PRD.
