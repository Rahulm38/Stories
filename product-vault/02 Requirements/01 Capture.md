# Capture

## Outcome

A user can preserve something worth telling in seconds without making organisational or scheduling decisions.

## Screen anatomy

```text
New memory

What's worth remembering?
A moment, idea or detail is enough. Write it naturally.

[ plain writing surface ]

↻ We'll bring this back in a few days.

[ Save memory ]
```

## Requirements

- The writing surface auto-focuses.
- Body text is the only required input.
- Save becomes available once non-whitespace text exists.
- New memories return automatically after 3 days.
- Draft text recovers after an interrupted capture.
- Leaving with unsaved content uses the native unsaved-changes guard.
- Successful save returns to Today with a short confirmation.

## Must not appear

- category or memory-type choice;
- folders or storage paths;
- source/context field;
- manual story/recall cue field;
- return-interval choice;
- formatting toolbar or syntax guidance;
- reflection prompt;
- title requirement.

## Copy principles

Use ordinary language. The user is saving something they want available later, not creating a study object.
