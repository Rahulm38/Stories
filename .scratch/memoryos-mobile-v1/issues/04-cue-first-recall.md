# 04 — Cue-first recall

**What to build:** Book learnings and experiences return at a useful time as a cue-first recall flow, then persist the next due date.

**Blocked by:** 01 — Capture to a local Markdown file

**Status:** ready-for-agent

- [ ] The note body is hidden until the user tries to recall and chooses Reveal.
- [ ] Later, Remembered, Partly, and Forgot each persist a deterministic next interval.
