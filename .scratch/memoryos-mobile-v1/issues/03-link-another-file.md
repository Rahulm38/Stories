# 03 — Link another file

**What to build:** A note can link another local Markdown file using Obsidian-style `[[...]]` syntax, with suggestions and native navigation.

**Blocked by:** 02 — Files to note

**Status:** ready-for-agent

- [x] Typing `[[` shows matching existing files and excludes the current file.
- [x] Selecting a suggestion inserts a folder-qualified canonical path.
- [x] Tapping a resolved link opens the intended note.
- [ ] A missing path opens a new draft in that path's folder.
- [ ] Rename and move preserve all path-qualified links.
